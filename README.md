# 🚀 Tudão

> Projeto desenvolvido para estudos e práticas de desenvolvimento web.

---

## 📋 Sobre o projeto

O **Tudão** é um projeto desenvolvido com o objetivo de colocar em prática conceitos de programação, desenvolvimento web, banco de dados e organização de projetos.

## 🛠️ Tecnologias utilizadas

- 💻 HTML
- 🎨 CSS
- ⚡ JavaScript
- 🐘 PHP
- 🗄️ MySQL
- 🔧 Git e GitHub

## 📁 Estrutura do projeto

```text
tudao/
├── public/
├── src/
├── vendor/
└── README.md
```

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone git@github.com:henderson2521190431010-ctrl/tudao.git
```

2. Entre na pasta:

```bash
cd tudao
```

3. Configure o banco de dados, caso necessário.

4. Execute o projeto utilizando o servidor adequado.

## 📌 Funcionalidades

- Cadastro de usuários
- Listagem de informações
- Edição de dados
- Exclusão de dados
- Integração com banco de dados
- Interface web
